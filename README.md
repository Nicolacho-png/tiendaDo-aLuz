# 🛒 Sistema POS - Tienda de Doña Luz

## 📝 Descripción
Aplicación de consola desarrollada en Java orientada a simular el sistema de caja registradora (Punto de Venta) para un negocio minorista. El software permite gestionar múltiples transacciones por turno, aplicar descuentos por membresía VIP, calcular de forma automática el cambio o dinero faltante, asignar obsequios según el volumen de compra y generar un reporte final de cierre de caja acumulado utilizando arreglos (`Arrays`).

## 🚀 Características Principales
*   **Gestión de Transacciones en Bucle:** Control iterativo mediante bucles `while` para procesar las compras de múltiples clientes de forma continua.
*   **Lógica de Descuentos y Promociones:** Aplicación de reglas de negocio como tarifas preferenciales para miembros VIP y entrega dinámica de obsequios por compras iguales o superiores a 5 artículos.
*   **Control de Efectivo:** Validación de pagos en efectivo con cálculo exacto de devuelta de dinero o advertencias por pagos incompletos.
*   **Cierre de Caja Estructurado:** Almacenamiento de nombres y montos en arreglos estáticos para generar un informe detallado de los clientes atendidos y el total de ventas al finalizar el turno.

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** Java 
*   **Entorno:** NetBeans / IntelliJ IDEA (Ejecución en Consola)

## ⚙️ Cómo ejecutar el proyecto
1. Clonar este repositorio en tu máquina local.
2. Abrir el proyecto en tu entorno de desarrollo (IDE) favorito compatible con Java.
3. Ejecutar la clase principal del sistema (`MiNiTienda.java`).
4. Seguir las instrucciones en la consola para registrar las compras, clientes y verificar el reporte de caja final.
